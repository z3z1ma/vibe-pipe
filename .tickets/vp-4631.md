# Add public API guard tests

## Objective alignment
Guard tests prevent public API drift and reintroduction of dead exports after pruning.

## Scope
- Add a test (e.g., `tests/test_public_api.py`) that validates `vibe_piper.__all__` entries are present.
- Ensure no private names (leading underscore) are exported.
- Verify core API symbols are never None and optional APIs can be None without test failure.

## Non-goals
- Extensive coverage of every optional feature behavior; just export integrity.

## Plan
1. Read `src/vibe_piper/__init__.py` and `PUBLIC_API_CURATION_ANALYSIS.md` for expected categories.
2. Implement tests for:
   - `__all__` names exist on the module.
   - No private names in `__all__`.
   - A minimal set of core symbols are non-None (Asset, AssetGraph, Pipeline, etc.).
3. Run unit tests.

## Acceptance criteria
- `uv run pytest tests/test_public_api.py -q` passes.
- Tests fail if any `__all__` entry is missing.

## Verification
- `uv run pytest tests/test_public_api.py -q`

## Risks / edge cases
- Optional features deliberately set to None; ensure the test allows that.

## Dependencies
- Depends on public API pruning ticket so the tests assert the final API.
