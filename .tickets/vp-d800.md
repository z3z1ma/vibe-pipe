# Remove web/dashboard/frontend stack

## Objective alignment
The library is a Python data pipeline core; web UI and dashboard scaffolding add bloat and dependencies that obscure the core API. Removing them simplifies the package and reduces maintenance.

## Scope
- Remove `src/vibe_piper/web/`, `src/vibe_piper/dashboard/`, `frontend/`, and `scripts/run_server.py`.
- Remove CLI commands related to dashboard/web (`src/vibe_piper/cli/commands/dashboard.py` and any CLI wiring).
- Remove docs tied to web/dashboard: `WEB_IMPLEMENTATION.md`, `docs/dashboard.md`, and README sections referencing dashboard/server.
- Remove Python dependencies only used by web/dashboard (fastapi, uvicorn, python-jose, passlib, python-multipart, email-validator).
- Update `pyproject.toml` scripts to drop `vibepiper-server`.
- Remove related tests (`tests/dashboard/` and any web-server tests).

## Non-goals
- Replacing web/dashboard with a new implementation.
- Changing core pipeline or quality APIs.

## Plan
1. Delete directories/files listed in Scope.
2. Remove CLI command registrations and exports in `src/vibe_piper/cli/commands/__init__.py` and any imports in `src/vibe_piper/cli/main.py`.
3. Update `pyproject.toml` dependencies and scripts; remove `vibepiper-server`.
4. Update README + docs to remove dashboard/web references.
5. Run lint and tests; fix fallout from removed modules.

## Acceptance criteria
- `frontend/`, `src/vibe_piper/web/`, `src/vibe_piper/dashboard/`, `WEB_IMPLEMENTATION.md`, and `docs/dashboard.md` are removed.
- `pyproject.toml` no longer lists web-related dependencies or `vibepiper-server` script.
- CLI no longer exposes dashboard/server commands.
- Tests and lint pass.

## Verification
- `uv run ruff check src tests`
- `uv run pytest -m "not integration"`

## Risks / edge cases
- Other modules may import dashboard/web; ensure all references are removed.
- Removing dependencies could affect unrelated modules if shared; verify by running tests.

## Dependencies
- Should land before README/docs cleanup ticket to avoid doc drift.
